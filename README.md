# 生词背诵工具

单文件网页版生词背诵工具，SM-2 间隔重复算法，支持朗文释义自动抓取与跨设备同步。

打开即用：**https://jessicaaa618.github.io/-/**

## 功能

- **SM-2 间隔重复**：四档自评（忘记 / 困难 / 良好 / 轻松），EF 1.3–2.8，按钮上直接显示「下次复习：N 天后」
- **每日节奏**：新学数量与复习上限分开计，新词满了只停新词
- **朗文释义**：自动抓 LDOCE5 的英文释义、音标、例句和发音，抓到后永久缓存
- **跨设备同步**：数据存在本仓库的 `data/vocab.json`，换设备填同样的令牌就能看到最新数据
- **备份**：导出 / 导入 JSON，另有每日快照兜底

## 跨设备同步怎么开

1. 打开网页 → 设置 → 跨设备同步
2. 新建令牌：GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens**
   - Repository access：只选这个仓库
   - Permissions：**Contents → Read and write**
3. 把令牌粘进设置页，点「开启同步」

之后在任意设备上：加词、评分、改设置都会自动推到云端；回到页面时会自动拉取别的设备的改动。

令牌只存在那台设备的浏览器 localStorage 里，不写进页面、不进导出备份。

> 注意：本仓库是公开的，`data/vocab.json` 里的词表数据谁拿到链接都能读。

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 全部功能（HTML + CSS + JS 单文件，无依赖） |
| `data/vocab.json` | 同步数据（首次开启同步时自动生成） |
| `生词表-边城精读-53词.txt` | 一份示例词表，可直接导入 |

## 导入格式

每行一个 `单词 | 释义`，也可以用 Tab 分隔。支持 `.txt` / `.csv` 上传，`#` 开头的行为注释。
